# Agent Scripts

## Purpose

エージェントが調査・解析・検証のために作成した補助スクリプトを置く。製品コードや通常ビルドに必要なツールは置かない。

## Layout

- スクリプトを `scripts/` 直下へ直接置かず、`scripts/<用途>/` のサブフォルダを作る
- 用途名は内容が分かる lowercase kebab-case とする
- スクリプト、テスト、用途固有の README は同じ用途フォルダにまとめる
- 別用途のスクリプトを同じフォルダへ混在させない

## Local Contracts

- リポジトリの通常ビルド・製品実行から参照しない
- 製品コードへ昇格する場合は、適切な製品ディレクトリへ移して通常のビルド・テスト規約に従う
- 各用途フォルダの README に目的、実行方法、前提、解析上の制約を記載する
