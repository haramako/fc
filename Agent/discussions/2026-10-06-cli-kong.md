# fcc のコマンドラインを kong に

## 背景

`fcc` のサブコマンドは 13 個（`lib` の下に 4 つ）あり、`main.go` の `switch` とコマンドごとの `flag.NewFlagSet` で振り分けていた。
`-t` / `-O` / `-D` / `-o` / `-g` をコマンドごとに定義し直していて、`--target` の別名の有無がそろっていなかった。使い方の文章は手書き。
標準の `flag` は最初のファイル名で読むのをやめるため、`fcc build main.fc -O 1` が通らなかった（roadmap の未判断「ソースの後ろのオプション」）。

## 検討

| 候補 | 増える依存 | スター（2026-10-06） |
|---|---|---|
| spf13/cobra | pflag・mousetrap・go-md2man・yaml | 約 44,700 |
| urfave/cli v3 | （テスト用だけ） | 約 24,300 |
| alecthomas/kong | なし（require はテスト用だけ） | 約 3,200 |
| 標準の flag + 自前の補助 | なし | — |

kong は構造体のタグでオプションを書き、共通のオプションを構造体の埋め込みでまとめられるので fcc の形に合う。
cobra は定番だが依存と書く量が多い（ほかの外部の依存は go.starlark.net だけ）。

## 決定事項（ユーザー）

- **kong にする**。GNU の getopt の形（`-O1`、短いオプションをまとめる、長い名前は `--`）は一般的なので問題ない
- **今の書き方との完全な互換は要らない**。`-md` → `--md`、`-cfg` / `-html` / `-rev` / `-dir` も `--`。`build -e` はやめた（`fcc run`）。
  `lib -C` の長い名前は `--directory`（`lib add --dir` とぶつかるため）、`-g` は `--debug-info`

## 確かめた kong の振る舞い（v1.16.1、scratchpad の試作と `cmd/fcc/main_test.go`）

- getopt_long と同じ: `-O1` / `-O 1`、`-gt nes`（まとめる）、`--opt=1` / `--opt 1`、`--` の後はファイル、`-` はファイル
- 違い:
  - 長い名前の前方一致（`--tar`）は受けない（エラー）
  - ファイルを複数取るコマンドで、オプションをファイルの**間**に挟むとエラー（`fmt a.fc -w b.fc`）。前か後ろならよい
  - 短いオプションの値が `-` で始まると受けない（`-O -1` → `--opt=-1`）
  - 値を省けるオプション（optional_argument）は無い
- 置ける場所: オプションは定義したコマンドの名前より後ろならどこでも。親のコマンドのオプション（トップの `-v` / `-h`、`lib` の `-C`）は
  サブコマンドの後ろにも書ける（`lib list -C p`）。サブコマンドのオプションをその名前より前には書けない（`fcc -t nes build` はエラー）
- **長い名前に `-` を 1 つ付けると、短いオプションの並びと読まれて黙って別の意味になる**（`-offline` が `-o ffline`）。
  知っている長い名前に `-` が 1 つのものは fcc 側でエラーにした（`checkSingleDash`）
- シェルの補完は kong の本体に無い。kong-completion（posener/complete を使う）は go 1.25 が要り、kongplete は 2024 から止まっている

## 補完（同じ日、ユーザーの依頼）

- `fcc completion zsh|bash` を自前で作った（依存なし）。スクリプトは補完のたびに `fcc __complete 語...` を呼び、fcc が kong のコマンドの
  木から候補を返す（コマンド・オプションを足してもスクリプトを作り直さなくてよい）。値の候補はタグ `complete:"..."`（`files=*.cfg`・`dirs`・
  `nes,emu` など。無ければ enum・プレースホルダ FILE / DIR・位置の引数は `*.fc`）
- bash は `COMP_WORDS` を与えて関数を呼び、zsh は zpty で TAB を送って確かめた（コマンド・オプションと説明・`-t` の値・`.fc` / `.dbg` の
  ファイル、fpath からの autoload と source の両方）
