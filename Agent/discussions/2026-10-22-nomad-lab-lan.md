# Nomad の試しを LAN から開けるようにする（2026-10-22）

## 背景

ユーザーが、Nomad の管理画面を LAN の別の PC から開きたいと言った（それまでは 127.0.0.1 だけで待ち受け）。

## 決定事項

- 開けるのと同時に ACL を有効にした。トークン無しは見るだけ（anonymous ポリシー）、操作は管理用のトークン、補充役には
  仕事を見る・dispatch・Variables の `lab/*` だけの専用のトークン。ACL が無いまま開くと、LAN の誰でも `raw_exec` と、ホストの
  フォルダを読み書きできる Docker の仕事で、このホストに任意のコマンドを実行できるため
- Nomad は有線 LAN（eno1）の IPv4 だけで待ち受ける（`GetInterfaceIP "eno1"`。アドレスが変わっても追従）。localhost では開けない
- 結果の集計（collector）は IPv4 の全部で待ち受ける（ほかの PC のワーカーも結果を送るので）

## 踏んだこと

- **Go のプログラムで `0.0.0.0` を指定すると、IPv6 のグローバルなアドレスでも待ち受けた**（Nomad も collector も。外から 200 が返る
  ことを確かめた）。最初は「IPv6 では待ち受けない」と説明していたが誤りだった。Nomad は特定のインターフェースの IPv4 に、
  collector は `tcp4` で開くように直した
- その間 ACL は有効だが bootstrap 前で、最初に bootstrap した人が管理者になれる状態だった。気づいてすぐ bootstrap した（成功したので
  先に誰かがしてはいない）。開ける前に bootstrap するのが正しい順番
