#   - if / while の条件 (cond=true): どちらかが符号付きなら `cmp` の N フラグ = (a-b) mod 256 の符号。
#     オーバーフロー補正が無いので |a-b| >= 128 のときだけ誤る (それ以外は正しい)
#   - 値として使う比較 (cond=false: `&&` / `||` の項、代入): 左辺が符号なし (リテラル含む) なら符号なし比較
#     → `vy > 0 || ...` は vy < 0 で真 (オーナーが踏んだ `||` のバグ)。左辺が符号付きなら N フラグ (上と同じ)
