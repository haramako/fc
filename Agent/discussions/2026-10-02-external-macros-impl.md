# 外部コマンドの定数マクロの実装で決めたこと

2026-10-02。ユーザーの依頼「外部コマンドで定数を作るマクロ（textmap はあとで）」の実装（段 1）。プロトコルと常駐は 2026-09-30 の
決定（`wiki/plans/external-macros.md`）どおり。実装しながら次の 2 点を決めた。

## マクロの名前を fc.toml に書く（`macros = [...]`）

- 計画では起動時のあいさつで名前を受け取るだけだった。それだと sema が `@名前` を知るために毎回プロセスを起動する必要があり、
  「マクロを使わないビルドでは起動しない」「キャッシュに全部当たれば起動しない」と両立しない
- **決定**: 名前は fc.toml の `macros` に書く。あいさつは照らし合わせ（fc.toml にあってサーバーに無ければエラー）に使う

## ディスクのキャッシュは `inputs` を書いたときだけ

- マクロのコマンド自身のソース（`go run ./tools/fcmacros` の Go のコード）を直しても fcc には分からず、キーに入らないと古い結果を
  使い続ける
- **決定**: fc.toml の `inputs`（コマンドのソースの glob）を書いたときだけ、その中身もキーに入れてディスク（`.fc-build/macros`）に
  置く。書かなければビルドの間のメモリのキャッシュだけ

## そのほか

- 起動するのはプロジェクトの fc.toml の `[macro_server.*]` だけ（ライブラリの fc.toml のものは使わない。「ビルドはライブラリの
  コードを実行しない」を保つ）
- テストはテストのバイナリ自身を `--fc-test-macro-server` 付きでサーバーとして起動する（`env` などに頼らず Windows の CI でも動く）
