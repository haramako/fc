# 書き方は tools/chrgen/main.go の頭。色の番号の約束: 0 = 透明・背景、1 = 輪郭 (暗い)、2 = 本体、3 = ハイライト (明るい)。
#
# BG ($0000)
#   $00〜$1F  8×8 の部品 (塗り・枠・点・落ちものの箱・ヘビ・リンゴ)
#   $20〜$7F  ASCII の文字 (fclib/nes/font.txt。色 3)
#   $80〜$8F  迷路の壁 (MAZE + 隣の向き)
#   $90〜$9F  マインスイーパー・ブロック崩しのブロック
#   $A0〜$FF  16×16 の絵 (n, n+1, n+16, n+17)
# スプライト ($1000): 16×16 は左上・左下・右上・右下、8×16 は上・下、8×8 は絵と空白 (8×16 のモードでも使える)
