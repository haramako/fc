# fc.toml

プロジェクトの設定のファイル。`fcc` はソースのディレクトリから親へ向かって最初に見つかった `fc.toml` を使う。
TOML の一部（`[見出し]`、`キー = 値`（`true` / `false`・整数・`"文字列"`・文字列の配列）、`#` から行末のコメント）だけを読む。
知らない見出しやキーはエラーにする（書き間違いを黙って無視しない）。

```toml
[target]
mapper = "MMC3"
prg = "128K"
chr = "8K"

[bank.stage]
slot = 0x8000

[ram.save]
start = 0x6000
size = 0x100

[define.pad]
REPEAT_DELAY = 20

[lib.util]
path = "../nes_util"
```

## [target]

NES の ROM の形。これがあれば、`-t` を省いても NES の ROM を作る。fc が ld65 の設定と iNES のヘッダを作る。

| キー | 値 | 既定 |
|---|---|---|
| `mapper` | `"NROM"` / `"UxROM"` / `"MMC1"` / `"MMC3"`（必須） | |
| `prg` | PRG ROM の大きさ（`"32K"` のように。マッパーのバンクの大きさの倍数） | `"32K"` |
| `chr` | CHR ROM の大きさ（8K の倍数）。`0` なら CHR RAM | `"8K"` |
| `mirroring` | `"vertical"` / `"horizontal"` / `"four"` | `"vertical"` |
| `battery` | バッテリーでセーブする RAM があるか | `false` |

マッパーごとのバンク:

| マッパー | 切り替える所 | 固定の所 |
|---|---|---|
| NROM | なし | `$8000`〜（32K 全部） |
| UxROM / MMC1 | `$8000` の 16K | `$C000` の 16K（最後のバンク） |
| MMC3 | `$8000` と `$A000` の 8K | `$C000` の 16K（最後の 2 つのバンク） |

## [bank.名前]

切り替えるバンクに名前を付ける。モジュールを `@(bank: "名前")` でそのバンクに置き、`@bank("名前")` でその番号を得る
（切り替えの関数に渡す）。何も指定しないモジュールは固定の所（`@(bank: "fixed")` と同じ）に入る。

| キー | 値 |
|---|---|
| `slot` | そのバンクを入れる番地（`0x8000` など。マッパーの切り替える所の 1 つ） |
| `index` | バンクの番号（省けば空いている番号を小さい順に） |
| `size` | バンクの大きさ（書くならマッパーのバンクの大きさと同じ） |
| `segments` | このバンクに置くアセンブリのセグメントの名前（文字列の配列） |

## [ram.名前]

RAM の場所に名前を付ける。変数を `@(segment: "名前")` でそこに置く（カートリッジの RAM `$6000`〜 のセーブデータなど）。

| キー | 値 |
|---|---|
| `start` | 始まりの番地 |
| `size` | 大きさ（バイト） |

`$0000`〜`$06FF` は fc が使う（ゼロページ・スタック・変数・静的フレーム）ので、重なるとエラーになる。`$0700`〜`$07FF` か
カートリッジの RAM を使う（スプライトの `oam` は既定で `$0700` を使う）。
カートリッジ RAM は起動時に 0 で埋めない。初期化とセーブデータの確認はプログラムで行う（[メモリ配置](./memory#初期化)）。

## [linker]

| キー | 値 |
|---|---|
| `extra` | ld65 の設定の断片のファイル。`MEMORY` と `SEGMENTS` の中身を fc が作る設定に足す |

## [define.モジュール名]

そのモジュールの `@(build)` を付けた定数の値を変える。

```toml
[define.frame]
QUEUE_SIZE = 96
```

コマンドラインの `-D frame.QUEUE_SIZE=96` はこの後に当てる。

## [lib.名前]

ほかのフォルダや git のリポジトリのモジュールを `use` で使えるようにする。

| キー | 値 |
|---|---|
| `path` | フォルダ（fc.toml からの相対） |
| `git` | git のリポジトリの URL |
| `rev` | タグ・ブランチ・コミット（省けば既定のブランチ） |
| `dir` | リポジトリの中のモジュールのあるディレクトリ（省けば一番上） |

- `use` は「ソースのディレクトリ → `[lib.*]`（書いた順。それぞれの下のターゲットの名前のディレクトリも）→ 標準ライブラリ」の順に探す。
  同じ名前のモジュールで標準ライブラリのものを置き換えられる。2 つのライブラリに同じ名前のモジュールがあればエラー
- git のライブラリはビルドのときにユーザーのキャッシュへ取ってきて、使ったコミットを fc.toml の隣の `fc.lock` に書く。以後のビルドは
  `fc.lock` のコミットを使う。`fcc lib update` で進める
- ライブラリの一番上に fc.toml があれば、その `[lib.*]` も使う（同じ名前ならプロジェクトの fc.toml に書いたものが勝つ）
- ビルドはライブラリのコードを実行しない（読むのはソース・アセンブリ・データのファイルだけ）

## [macro_script.名前]

定数を作るマクロを、Starlark（Python に似た小さな言語）のスクリプトで足す（表の生成・アセットの変換など）。`fcc` の中で動くので、
ほかに何も入れなくてよい。ソースでは組み込みと同じく `@名前(引数)` と書き、結果は定数になる。

```toml
[macro_script.tables]
file = "tools/tables.star"
```

```python
# tools/tables.star
def sin_table(n, amp):
    return fc.array("i8", [int(math.round(amp * math.sin(2 * math.pi * i / n))) for i in range(n)])

def font_widths(pattern):
    return [len(read(f)) // 8 for f in glob(pattern)]   # 0..255 の整数のリストは [N]u8
```

<!-- ignore: tools/tables.star が無いと動かない -->
```fc ignore
const SIN = @sin_table(256, 64);
const W = @font_widths("res/font/*.chr");
```

- スクリプトの一番上の関数（`_` で始まらないもの）がマクロになる。組み込みと同じ名前はエラー
- スクリプトはファイル・時刻・乱数・OS に触れられない。使えるのは次のものだけ:

| 名前 | 中身 |
|---|---|
| `read(path)` | ファイルの中身（bytes）。fc.toml のあるディレクトリの中だけ読める |
| `glob(pattern)` | ファイルの一覧（名前の順。同じく fc.toml のあるディレクトリの中） |
| `math` | `math.sin`・`math.floor`・`math.pi` など |
| `fc.array(type, list)` | 型付きの整数の配列（`type` は `"u8"` / `"i8"` / `"u16"` / `"i16"`） |
| `fc.int(type, n)` | 型付きの整数 |
| `print(...)` | 標準エラーに出す（デバッグ用） |
| `load("x.star", "f")` | 同じディレクトリ（の下）の別のスクリプトの関数を使う |

- 引数は定数の整数・文字列・整数の配列（`u8` の配列は bytes になる）
- 戻り値は整数（型のない定数）・文字列・bytes（`[N]u8`）・整数のリスト（全部 0..255 なら `[N]u8`。それ以外は `fc.array` で型を書く）・
  `fc.array`・`fc.int`
- bytes の添字は 1 バイトの bytes で、`+` でつなげない。整数で扱うときは `list(b.elems())` にし、`bytes(list)` で戻す
- 止まらないマクロは一定の手数で打ち切ってエラーにする

## [macro_server.名前]

定数を作るマクロを、外部のコマンドで足す（Go など好きな言語で書ける。`[macro_script.*]` で足りないとき）。ソースでは組み込みと同じく `@名前(引数)` と書き、
結果は定数になる。

```toml
[macro_server.tools]
command = ["go", "run", "./tools/fcmacros"]
macros = ["sin_table"]
inputs = ["tools/fcmacros/*.go"]
```

<!-- ignore: マクロのコマンドが無いと動かない -->
```fc ignore
const SIN = @sin_table(256, 64);
```

| キー | 値 |
|---|---|
| `command` | 起動するコマンドと引数（文字列の配列）。作業ディレクトリは fc.toml のあるディレクトリ |
| `macros` | 提供するマクロの名前（`@` を除く）。組み込みと同じ名前はエラー |
| `inputs` | 省略可。コマンド自身のソースのファイル（glob、fc.toml からの相対）。書くと結果をディスクにキャッシュする |

- コマンドはマクロを最初に使ったときに起動し、ビルドの間だけ動かしておく。マクロを使わないビルドでは起動しない
- やり取りは標準入出力の 1 行に 1 つの JSON。起動したら最初の行で `{"macros": ["sin_table"]}` を書く。
  要求は `{"id": 1, "macro": "sin_table", "args": [256, 64]}` で、`{"id": 1, "result": …, "deps": ["…"]}` か
  `{"id": 1, "error": "…"}` を返す。エラーはマクロを呼んだ位置のエラーになる。マクロのログは標準エラーに書く（そのまま表示される）
- 引数は定数の整数・文字列・整数の配列（`u8` の配列は `{"bytes": "<base64>"}`）
- `result` は次のどれか:
  - `{"int": 5}`（`"type": "u8"` などを付ければ型付き）
  - `{"type": "i8", "data": [0, 1, …]}`（`[N]i8` の配列。`type` は `u8` / `i8` / `u16` / `i16`）
  - `{"bytes": "<base64>"}`（`[N]u8` の配列）
  - `{"string": "…"}`（文字列）
- `deps` はマクロが読んだファイル（fc.toml からの相対）。`inputs` を書いたときは「コマンド・`inputs` の中身・マクロ名・引数」で
  結果を中間生成物のディレクトリに置き、次のビルドで `deps` のファイルが変わっていなければコマンドを起動せずにそれを使う。
  `inputs` が無ければキャッシュはビルドの間だけ（コマンドが変わったことが分からないので）
- 使うのはプロジェクトの fc.toml の `[macro_server.*]` だけ（ライブラリの fc.toml のものは起動しない）
