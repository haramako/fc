# アセンブリとの連携

ca65 のアセンブリを組み込むときの宣言と呼び出し規約。fc の関数の書き方は[言語仕様](./language#関数)、領域の使い方は[メモリ配置](./memory)を参照。

## ファイルとシンボル

`@include("file.asm")` でアセンブリをモジュールに入れ、本体の無い関数の宣言で呼ぶ。本体の無い関数には `@(abi: …)` が必須。
ファイルはソースのディレクトリ、fc.toml のライブラリ、標準ライブラリの順に探す。

```fc
function fill_raw(dst:*u8, n:u16, v:u8):void @(abi: "frame");
@include("mem.asm");

var status:u8 @(symbol: "status");

function reset():void
{
	@asm("lda #0", "sta status");
}
```

`@asm` は引数の文字列ごとにアセンブリを 1 行出す。関数と変数のシンボルは、指定がなければ `_モジュール名_名前`。
`@(symbol: "名前")` で指定できる。

## 呼び出し規約 {#calling-conventions}

| 属性 | 引数と戻り値 |
|---|---|
| `@(abi: "frame")` | 関数ごとの固定の領域に、戻り値 → 引数の順に置く。引数をレジスタでは渡さない |
| `@(abi: "stack")` | fc のスタック `S+k,x` で渡す。呼び出される asm 関数は X を保存する |
| `@(abi: "cc65")` | cc65 の `__fastcall__`。引数は 0〜1 個、戻り値は void か 1〜2 バイト。1 バイトは A、2 バイトは A（下位）/ X（上位） |

### frame

関数のシンボルが `_mem_fill_raw` なら、領域の先頭は `F_mem_fill_raw`。戻り値を先頭に置き、続いて引数を宣言の順に詰める。
複数バイトの値は下位バイトが先。生成される `.fc-build/_frames.inc` の `F_mem_fill_raw__dst` のような名前で引数を参照できる。

- A / X / Y は壊してよい。
- 本体の無い関数に `@(scratch: N)` を付けると、引数の後ろに作業用の N バイト（0〜255）を取る。先頭は `F_シンボル__scratch`。
- 既定ではゼロページに置く。入り切らなければエラー。間接アドレスとして使わない関数なら `@(zeropage: false)` で RAM に置ける。
- 再帰と、関数のアドレスを取ること（関数ポインタ）はできない。
- **asm の関数から、同じモジュールの `abi: "frame"` の asm 関数を呼んではいけない。** コンパイラがその呼び出しを認識できず、
  両者の引数や作業領域を重ねて置くことがある。asm 内の補助処理は、fc の関数として宣言せず、呼び出し元の作業領域を使うラベルにする。

実例は [mem.asm](https://github.com/haramako/fc/blob/main/fclib/mem.asm) と
[lzw.asm](https://github.com/haramako/fc/blob/main/fclib/lzw.asm) にある。
asm から呼ぶ fc の関数にも `@(abi: "frame")` を付ければ、この固定の規約を使える。

### cc65

呼び先は A / X / Y を壊してよい。引数が 2 個以上ある関数や、3 バイト以上の引数・戻り値は扱えない。
関数のアドレスは取れず、別のバンクへの far call もできない。常に見える場所にある関数なら `@(near)` を指定する。

## 割り込みから呼ぶ関数

fc の関数には `@(interrupt)` を付ける。その関数と、そこから呼ぶ関数の変数は、ほかの処理と領域を共有しない。
再帰する関数や `@(abi: "stack")` の関数は割り込みから呼べない。
同じ関数を通常の処理と割り込みの両方から呼ぶと、その関数自身の領域は共有される。通常の呼び出し中に割り込んで再び呼ぶ使い方はできない。

領域を分けても、掛け算・割り算・ポインタ経由の読み書きなどが使う共通の作業域までは保護しない。
NMI の処理を追加する場合は [frame.hook](./std/nes/frame) の制約も確認する。

## リンクと土台の指定

`main` のモジュールで次の属性を指定できる。パスは入口のソースのディレクトリからの相対。

| 属性 | 意味 |
|---|---|
| `@(link: "sound.o driver.lib")` | 追加のオブジェクトやライブラリをリンクする（空白区切り） |
| `@(linker_config: "ld65.cfg")` | 自前のリンカ設定を使う |
| `@(base: "base.asm")` | fc が生成する `base.s` の代わりに、指定したファイルをアセンブルする |

独自の土台は `L` / `reg` / `FC_FASTCALL_REG` / `FC_SZP` / `FC_SRAM` / `FC_SP` / `FC_FARCALL`、NES のヘッダとベクタを用意する必要がある。
`FC_SZP_SIZE` / `FC_SRAM_SIZE` などの領域の大きさも実際の予約量に合わせる。
通常の ROM 構成は [fc.toml](./fc-toml) で指定できる。
